# Отложенные задачи

Машинист иногда просит что-то не делать прямо сейчас, а просто записать на потом — чтобы
сделать несколько таких правок разом. Этот файл — список таких заметок. Когда задачу делаем,
вычёркиваем (или удаляем) пункт из списка в том же коммите, где делаем саму правку.

- [ ] Экран не должен гаснуть, пока приложение открыто (держать его всегда активным,
      `FLAG_KEEP_SCREEN_ON` / `android:keepScreenOn` на главном экране).
