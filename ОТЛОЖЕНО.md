# Отложенные задачи

Машинист иногда просит что-то не делать прямо сейчас, а просто записать на потом — чтобы
сделать несколько таких правок разом. Этот файл — список таких заметок. Когда задачу делаем,
вычёркиваем (или удаляем) пункт из списка в том же коммите, где делаем саму правку.

- [ ] Полноценное стартовое "Меню" (раньше машинист его вычёркивал, не мог вспомнить, зачем
      оно нужно — теперь вспомнил и описал подробнее). При запуске приложение открывается не
      сразу на главный экран, а сначала показывает меню с пунктами:
      1. Запустить приложение (переход на обычный главный экран, как сейчас).
      2. Обновление базы данных — экран, где машинист сам может закинуть файл с новыми
         данными (профиль пути, скорости, сигналы и т.п.) без участия Claude, и приложение
         подхватит обновлённые данные само.
      3. Настройки — пока не до конца продуман, предположительно: громкость звуков, и
         отдельно настраиваемые пороги расстояний для голосовых оповещений (сейчас в коде
         зашиты фиксированные значения — переезд за 1500/800/300 м, временное ограничение за
         2000 м и т.д., см. MainActivity/PointAnnouncementScheduler) — чтобы можно было
         поменять их самому, если в инструкции по ТЧМ эти расстояния изменятся, не прося
         каждый раз менять код.
