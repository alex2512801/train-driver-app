# Отложенные задачи

Машинист иногда просит что-то не делать прямо сейчас, а просто записать на потом — чтобы
сделать несколько таких правок разом. Этот файл — список таких заметок. Когда задачу делаем,
вычёркиваем (или удаляем) пункт из списка в том же коммите, где делаем саму правку.

- [ ] Третий пункт стартового меню — "Настройки" (первые два — запуск приложения и база
      данных — уже сделаны, см. MenuActivity/DatabaseActivity). Пока не до конца продуман,
      предположительно: громкость звуков, и отдельно настраиваемые пороги расстояний для
      голосовых оповещений (сейчас в коде зашиты фиксированные значения — переезд за
      1500/800/300 м, временное ограничение за 2000 м и т.д., см. MainActivity/
      PointAnnouncementScheduler) — чтобы можно было поменять их самому, если в инструкции по
      ТЧМ эти расстояния изменятся, не прося каждый раз менять код.
